## 这个小站是做什么的

就一句话：**给自己留个写字的地方**。

以前学东西总是看过就忘，笔记散落在各种临时文件里，找的时候又得翻一遍。
与其这样，不如放到一个固定的地方 —— 顺便也逼自己把话说清楚，
因为「写明白」比「看懂了」难得多。

## 我打算写什么

不给自己定更新频率，有想说的就写。大概三类：

- **Rust 学习笔记** —— 最近在啃官方书和 rustlings，踩过的坑记下来。
- **Linux 桌面折腾** —— Arch + niri + Neovim，配置一次忘一次，得留档。
- **随想与音乐** —— 主要是 Vocaloid，偶尔写点不成体系的想法。

## 关于我

**KirisameNyan**。喜欢命令行、代码和音乐。想找我的话，侧边栏有 GitHub 链接。

## 关于这个站

技术上没什么特别的：基于 [Astro](https://astro.build/) 构建，主题是 [Firefly](https://github.com/CuteLeaf/Firefly)，
托管在 GitHub Pages，推一次代码自动部署。

稍微花心思的地方是配置 —— Firefly 的配置项散在二十多个 TypeScript 文件里，
纯手改容易出错，所以我另写了一个桌面工具 **Firefly Studio** 来做图形化编辑：
它读 Firefly 的类型定义和注释自动生成表单，改动写成对源码的精确文本替换，
注释和格式都不会被动，改完还能跑一次类型检查确认没写坏。

想了解细节的话，以后可能会单独写一篇。
