## 报错内容

更新完Arch之后就出现这个问题了，报错如下:

```PACMAN
错误：GPGME 错误：无数据
错误：GPGME 错误：无数据
错误：GPGME 错误：无数据
:: 正在同步软件包数据库...
 core                                                                                                              128.5 KiB   355 KiB/s 00:00 [########################################################################################] 100%
 extra                                                                                                               8.4 MiB  2.88 MiB/s 00:03 [########################################################################################] 100%
 multilib                                                                                                           84.0 KiB   228 KiB/s 00:00 [########################################################################################] 100%
 archlinuxcn 已经是最新版本
 blackarch 已经是最新版本
错误：GPGME 错误：无数据
```

也可能是这种

```PACMAN

错误：GPGME 错误：无数据
错误：GPGME 错误：无数据
错误：数据库 'core' 无效 (无效或已损坏的数据库 (PGP 签名))
错误：数据库 'extra' 无效 (无效或已损坏的数据库 (PGP 签名))
错误：数据库 'multilib' 无效 (无效或已损坏的数据库 (PGP 签名))
```
第一种是在滚系统时触发的，第二种则是在安装软件时触发的

## 解决方案

超级简单，一行命令

```COMMAND
sudo rm /var/lib/pacman/sync/*.sig
```
解决了喵

## 问题原因

pacman更新时会尝试下载`$repo.db.sig`这个文件，`$repo`指的是仓库名，而大多数的源，数据库文件不会被签名，所以镜像站会返回404,因而pacman就会忽略这些东西

而当你在一个需要登录验证的网络里，`.db.sig`被劫持，得到200而不是404,从而引起问题
